Privacy policy

Prom autopilot · effective 14 October 2026

Who uses the app

Prom autopilot is an internal tool used only by the owner of the Vision Dynamics store on Prom.ua. It is not offered to the public and has no other users.

What Google data it accesses

With the owner's consent (scope https://www.googleapis.com/auth/adwords) the app calls the Google Ads API to read Keyword Planner historical metrics (average monthly searches) for search phrases related to the store's own products. It does not read personal data, contacts, emails or files.

How the data is used

The numbers are used only to order search phrases in the store's own product cards. The app does not create, edit or delete ads, campaigns, budgets or account settings.

Storage and sharing

  • Access credentials are kept as encrypted GitHub Actions secrets of the owner's private repository.
  • Search-volume numbers are not stored separately; only the resulting order of phrases is saved in the owner's own spreadsheet.
  • Data is not sold, shared with third parties, or used for advertising or AI model training.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: open an issue in the prom-autopilot-info repository.
